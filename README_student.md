# Практическая работа №7

## Тема

DOM и управление элементами HTML-страницы средствами JavaScript.

## Запуск

В этой работе используется браузерный DOM, поэтому `node tests.js` не применяется.

1. Откройте `practice.html` в браузере, чтобы видеть результат работы функций.
2. Заполните участки `TODO` в `student-template.js`.
3. Для автоматической проверки откройте `test-runner.html` в браузере.
4. Все шесть тестов должны завершиться сообщением `Все тесты пройдены.`

Сторонние библиотеки и npm-пакеты не нужны.

## Что нельзя изменять

Не изменяйте:

- имена функций в `student-template.js`;
- их параметры;
- объект `window.domLab` в конце файла;
- идентификаторы элементов в `practice.html`, если это не требуется условием.

Основная работа выполняется именно в `student-template.js`.

## Сдача

Для этой работы отдельная загрузка в учебную систему не требуется. Работа выполняется в привычном GitHub-репозитории.

В репозитории должны оставаться `practice.html`, `styles.css`, заполненный `student-template.js`, `tests.js`, `test-runner.html` и при необходимости краткое описание запуска.
